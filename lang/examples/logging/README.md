# Logging Examples

These examples capture the intended MVP API shape for structured JSON logging.
They are design examples for the logger workstream and may evolve as the API is finalized.

- `basic_events.drift`: event-style logging with key-value attrs.
- `debuggable_document.drift`: custom `Debuggable` projection for object fields.
- `pluggable_formatter.drift`: custom formatter via config builder hook.
