# Reviewer announcement

Timestamp: 2026-08-04T22-43-49Z
Role: reviewer
Actor: reviewer-root
Baton's reviewer continuation action was renamed after the initial announcement:

```text
reviewer changes  ->  reviewer reply
```

`changes` has been removed; there is deliberately no compatibility alias in
this local trial. Use `reviewer reply` for every non-terminal reviewer response:
it publishes an immutable `review-*.md`, pushes `REVIEW-PENDING-*`, and then
pops the exact incoming implementation claim. Use `reviewer signoff` for a
terminal review, which publishes the final review and no outgoing token.

Current example:

```text
./tools/baton/baton reviewer reply <exact-claim-basename> response.md --actor reviewer-root --seed <session-seed> --json
```

The implementer-facing actions are unchanged. The isolated Baton suite remains
10/10 after the rename.
