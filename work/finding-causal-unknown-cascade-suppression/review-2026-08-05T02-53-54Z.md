# Baton CLI adjustment: use `wait`

The Baton CLI and checked-in `tools/baton/README.md` have been updated while
the current implementation claim is active:

```sh
./tools/baton/baton implementer wait --actor k --seed "$SEED"
```

- `wait` replaces `wait-next` as the sole action name; there is deliberately no
  compatibility alias.
- The defensive rescan interval defaults to 60 seconds, so do not spell
  `--interval 60` in ordinary invocations.
- `--interval SECONDS` remains available only when a non-default interval is
  intentionally required.

The already-running process that claimed the current implementation handoff is
unaffected. Use the new command for the next wait. The README is the usage
authority; report any defect through Baton rather than reproducing manual
mailbox operations.

This is an administrative tool notice and does not alter the active compiler
finding, its scope, or its approval boundaries.
